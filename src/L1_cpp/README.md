# L1 · 读数统计（cpp）

读取 n 个整数，输出 `count / sum / min / max` 四项。

## 构建

```bash
g++ -std=c++17 -o main main.cpp
```

## 运行

```bash
./main
```

**输入**：第一行一个整数 `n`；第二行 `n` 个整数，空格分隔。
**输出**：恰好四行 `count=` / `sum=` / `min=` / `max=`。

## 样例

输入：

```
5
1 2 3 4 -1
```

输出：

```
count=5
sum=9
min=-1
max=4
```

## 要点

- `min` / `max` 必须用**读到的第一个值**初始化，不能用 `0` 兜底（否则全负数时 max 错成 0）。
- 退出码为 `0`。
